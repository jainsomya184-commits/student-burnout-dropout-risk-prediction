
# Student Burnout & Dropout Risk Prediction

An end-to-end Machine Learning project analyzing academic, lifestyle, and behavioral factors to predict student burnout and risk of dropout.

## Overview
- **Data Preprocessing & Cleaning:** Handled missing values, null values, and duplicate records.
- **Exploratory Data Analysis (EDA):** Analyzed correlations between stress levels, study hours, attendance, and burnout.
- **Model Training:** Built classification models to identify students at risk of burnout and dropout.

## Tech Stack
- Python
- Pandas, NumPy
- Matplotlib, Seaborn
- Scikit-Learn
- Google Colab

## How to Run
Open and run directly in Google Colab using the notebook link above!
